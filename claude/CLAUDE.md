## Tooling for shell interactions

When finding FILES, use 'fd'
When finding TEXT/strings, use 'rg'
When finding CODE STRUCTURE, use 'ast-grep'
When interacting with JSON, use 'jq'
When interacting with YAML or XML, use 'yq'

- Use `eza --tree` instead of `ls --tree`

## Git Operations

When committing to git, do not include "Generated with..." in the commit message.
